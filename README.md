# Ferreira Defesa — Landing page em Astro

Implementação responsiva inspirada na referência fornecida, com componentes reutilizáveis, navegação por âncoras, menu mobile, FAQ nativo e microinterações acessíveis.

## Como executar

1. Instale as dependências: `pnpm install`
2. Inicie em desenvolvimento: `pnpm dev`
3. Gere a versão de produção: `pnpm build`
4. Visualize a produção local: `pnpm preview`

O conteúdo principal fica em `src/pages/index.astro`, os blocos da página em `src/components` e os tokens/estilos globais em `src/styles/global.css`.
